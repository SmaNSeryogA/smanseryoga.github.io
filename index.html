Mozg Bestiary

Личный инструмент канала «Бестиарий» — «Твари, которые охотятся на твои деньги, время и нервы».

Политика конфиденциальностиУсловияEnglish

Что делает приложение

  • Загружает на YouTube-канал «Бестиарий» ролики, которые подготовил и одобрил владелец канала.
  • Перед загрузкой проверяет, что ролик предназначен именно этому каналу и не публиковался раньше.
  • Читает статистику канала (просмотры, удержание, комментарии) для отчётов владельцу.

Приложение работает только на компьютере владельца, только с его аккаунтом и не предлагается другим людям. Оно использует YouTube API Services. Какие данные оно получает и как их удалить — в политике конфиденциальности.

Пользуясь приложением, вы соглашаетесь с Условиями использования YouTube и Политикой конфиденциальности Google. Приложение предназначено только для владельца канала «Бестиарий».

Mozg Bestiary

A personal tool of the YouTube channel “Бестиарий” (Bestiary).

What it does

  • Uploads videos prepared and approved by the channel owner to the “Бестиарий” YouTube channel.
  • Before uploading, checks that the video is meant for this channel and has not been published before.
  • Reads channel statistics (views, retention, comments) for reports to the owner.

It runs only on the owner’s computer, only with the owner’s account, and is not offered to other people. It uses YouTube API Services — see the Privacy Policy.
